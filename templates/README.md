# Note Templates

这里放个人知识库的笔记模板。写新笔记时可以复制对应模板，减少每次重新组织结构的成本。

模板统一使用中文 `文档信息` 表格，不再使用 YAML front matter。字段固定为 `主题`、`类型`、`状态`、`创建时间`、`更新时间`，方便阅读和后续检索。

## 模板列表

- [概念笔记](concept.md): 解释一个机制、术语或模型。
- [源码阅读](source-map.md): 记录入口、调用链、数据结构和源码坐标。
- [问题复盘](debug.md): 记录问题现象、定位过程、根因和后续检查项。
- [阶段总结](summary.md): 总结一段时间的学习成果和下一步问题。
